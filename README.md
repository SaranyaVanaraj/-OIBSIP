# OIBSIP – Data Analytics Internship

## About the Internship

This repository contains the projects completed as part of my **Data Analytics Internship at Oasis Infobyte (OIBSIP)**. These projects provide practical experience in data analysis, data preprocessing, exploratory data analysis, data visualization, and extracting meaningful insights from datasets using Python.

The tasks cover different analytical domains, including retail sales analysis, customer segmentation, fraud detection, and Android app market analysis. Each project focuses on understanding data, identifying patterns, investigating trends, and deriving insights that can support data-driven decision-making.

## Internship Details

- **Organization:** Oasis Infobyte
- **Internship Program:** OIBSIP
- **Domain:** Data Analytics

## Objectives

The main objectives of these projects are to:

- Develop practical skills in Python-based data analytics.
- Understand and implement data cleaning and preprocessing techniques.
- Perform Exploratory Data Analysis (EDA) to identify patterns and trends.
- Apply appropriate analytical and statistical techniques to datasets.
- Create visualizations to communicate findings effectively.
- Analyze customer behavior, business performance, and unusual data patterns.
- Extract meaningful insights to support informed decision-making.
- Improve analytical thinking, problem-solving, and technical documentation skills.

## Tasks Completed

### Level 1 – Task 1: EDA Retail Sales

**Overview**

The EDA Retail Sales project focuses on exploring retail sales data to understand sales performance, product trends, and customer purchasing patterns. Exploratory Data Analysis techniques are used to examine the dataset, summarize important variables, and identify patterns that can help explain business performance.

**Key Activities**
- Loading and inspecting the retail sales dataset.
- Examining data types, missing values, and duplicate records.
- Cleaning and preparing the data for analysis.
- Analyzing sales figures and relevant business variables.
- Identifying trends and patterns in retail transactions.
- Creating visualizations to communicate important findings.

**Outcome**

This project develops an understanding of retail sales data and demonstrates how exploratory analysis can help identify business trends and support data-driven decisions.

### Level 1 – Task 2: Customer Segmentation

**Overview**

The Customer Segmentation project focuses on grouping customers according to relevant characteristics and behavioral patterns. Segmentation helps identify different customer groups and understand how their needs or purchasing behaviors may vary.

**Key Activities**
- Loading and exploring the customer dataset.
- Cleaning and preprocessing relevant variables.
- Examining customer characteristics and behavioral patterns.
- Applying suitable analytical or segmentation techniques.
- Visualizing customer groups and their characteristics.
- Interpreting the results to understand differences between segments.

**Outcome**

This project demonstrates how data analysis and customer segmentation techniques can help businesses understand their customers, identify distinct groups, and make more informed marketing and business decisions.

### Level 1 – Task 3: Fraud Detection

**Overview**

The Fraud Detection project focuses on analyzing transaction data to identify potentially suspicious patterns and distinguish unusual transactions from normal activity. The project demonstrates how data analysis techniques can support fraud investigation and risk identification.

**Key Activities**
- Loading and exploring the transaction dataset.
- Examining the data structure, variables, and class distribution.
- Cleaning and preprocessing data where necessary.
- Investigating patterns associated with fraudulent and legitimate transactions.
- Applying appropriate analytical techniques to identify suspicious activity.
- Visualizing relevant findings and interpreting the results.

**Outcome**

This project provides practical exposure to fraud-related data analysis and demonstrates the importance of identifying unusual transaction patterns. The results can support further investigation and risk assessment, although analytical predictions should not be treated as definitive proof of fraud.

### Level 2 – Task 4: Android App Market Analysis

**Overview**

The Android App Market Analysis project explores Google Play Store data to understand application categories, ratings, installation patterns, pricing strategies, and user feedback. The analysis combines application information with user reviews to identify market trends and potential opportunities for Android app developers.

**Key Activities**
- **Data Loading and Exploration:** Imported the Google Play Store datasets and examined their dimensions, columns, and data types.
- **Data Cleaning and Preprocessing:** Identified missing values, removed duplicate records, converted relevant columns into appropriate data types, and handled invalid values.
- **App Category Analysis:** Examined the distribution of applications across different categories to understand market representation.
- **Rating Analysis:** Investigated rating distributions and compared average ratings across categories.
- **App Size and Installs Analysis:** Explored the relationship between application size and reported installation counts.
- **Free and Paid App Analysis:** Compared free and paid applications and examined paid app prices.
- **Estimated Revenue Analysis:** Calculated approximate revenue using app prices and reported install counts, with the understanding that this is not actual verified revenue.
- **Sentiment Analysis:** Used TextBlob to classify translated user reviews as positive, negative, or neutral.
- **Developer Insights:** Examined category competition, ratings, and user sentiment to identify possible areas for improvement.

**Outcome**

This project demonstrates how data analysis and sentiment analysis can be used to explore the Android app market, understand user feedback, compare application categories, and identify potential opportunities for developers.

## Tools and Technologies

The following tools and libraries are used across the projects, where applicable:

- **Python:** For data processing, analysis, and implementation of analytical techniques.
- **Jupyter Notebook:** For interactive coding, documentation, and presentation of analytical results.
- **Pandas:** For data loading, cleaning, transformation, grouping, and analysis.
- **NumPy:** For numerical operations and data manipulation.
- **Matplotlib:** For creating charts and visualizing analytical findings.
- **Seaborn:** For statistical visualizations and examining relationships between variables.
- **TextBlob:** For basic sentiment analysis of text-based reviews.
- **Plotly:** For interactive data visualizations where required.

## Data Analytics Workflow

The projects follow a structured workflow adapted to each task:

1. **Data Collection:** Obtaining the datasets required for analysis.
2. **Data Understanding:** Examining the dataset structure, variables, and data types.
3. **Data Cleaning:** Identifying and handling missing values, duplicate records, and inconsistencies.
4. **Data Preprocessing:** Preparing variables and converting data into suitable formats.
5. **Exploratory Data Analysis:** Using descriptive statistics, comparisons, and grouping to understand the data.
6. **Data Visualization:** Creating charts and graphs to communicate patterns and trends.
7. **Interpretation:** Evaluating the results and identifying meaningful insights.
8. **Documentation:** Recording the methodology, observations, limitations, and conclusions.
